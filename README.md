## ⚡ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Anupkumar-mishra/Personal-Portfolio-Anup-.git
```

Move into project folder:

```bash
cd Personal-Portfolio-Anup-
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open browser:

```bash
http://localhost:3000
```
