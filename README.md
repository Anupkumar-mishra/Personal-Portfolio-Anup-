# ⚡ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/Anupkumar-mishra/Personal-Portfolio-Anup-.git
```

---

## Move Into Project Folder

```bash
cd Personal-Portfolio-Anup-
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

---

## Open Browser

```bash
http://localhost:3000
```
