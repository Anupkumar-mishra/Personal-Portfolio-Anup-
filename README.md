# Anup Kumar Portfolio

Modern developer portfolio built using Next.js, TypeScript and Tailwind CSS.

## Features

- Modern UI/UX
- Responsive Design
- Smooth Animations
- Projects Showcase
- Contact Section
- Dark Theme

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
